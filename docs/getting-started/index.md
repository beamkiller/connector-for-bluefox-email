# Getting started

Setting up the plugin takes about fifteen minutes. You need admin access to your WordPress site and to your bluefox.email project.

1. [Install](install.md) the plugin.
2. [Connect](connect.md): enter the project ID and API key, test the connection and load your lists.
3. [Set up your bluefox list](bluefox-list.md): double opt-in, the confirmation email and the redirect link.
4. [Switch on features](features.md) on the **General** tab.
5. [Create the thank-you and preferences pages](pages.md).
6. [Register the webhook](webhook.md) so confirmations reach WordPress within seconds.

The plugin adds a top-level **bluefox.email** menu to wp-admin. Each feature you switch on gets its own tab there.

!!! tip "Test on a staging site first"
    New bluefox.email projects start in a sandbox with a small daily sending limit. Run through a full signup (form → confirmation email → thank-you page → coupon) on a staging copy before you go live.
